# GitHub Repository Metadata Configurations

This document outlines the metadata configurations that the repository owner should set up on the GitHub dashboard.

---

## 1. Repository Description
Set the repository description on GitHub to:
```
AI-powered stock intelligence and automated trading platform for Indian markets built with FastAPI, React, Firebase, Gemini AI, Firestore, and Upstox.
```

---

## 2. GitHub Topics
Assign the following tags to the repository:
* `ai`
* `artificial-intelligence`
* `stock-market`
* `algorithmic-trading`
* `fintech`
* `python`
* `fastapi`
* `react`
* `typescript`
* `firebase`
* `firestore`
* `gemini`
* `upstox`
* `telegram`
