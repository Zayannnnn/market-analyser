# GitHub Discussions Guidelines for AORA Engine

GitHub Discussions is our primary forum for community questions, ideas updates, announcements, and showcases. We utilize four structured categories:

---

## 1. Announcements 📢
* **Purpose**: Hosted solely by maintainers for release announcements, scheduled network outages, API compatibility deprecations, and major project roadmap revisions.
* **Format**: Thread locks enabled. Read-only access for users, with comments open.

---

## 2. Q&A ❓
* **Purpose**: Community support questions regarding local environments setup, Firebase admin credentials configuration, Upstox API redirects troubleshooting, and generic execution mode questions.
* **Format**: Solved answer checks enabled. Users can accept specific community answers as resolutions.

---

## 3. Ideas 💡
* **Purpose**: Proposing new broker routing endpoints, localized model pipelines configurations, portfolio rotation strategies, and UI upgrades.
* **Format**: Voting and reactions enabled. Thread updates will map directly to issues.

---

## 4. Show and Tell 🙌
* **Purpose**: Showcasing custom portfolio setups, paper trading logs performance highlights, Telegram alerts visual custom templates, or custom modules integrations.
* **Format**: Open conversation threads with image uploads enabled.
